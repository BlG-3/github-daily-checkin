# GitHub每日打卡

每天完成一个小项目，从简单、可运行的作品开始，逐渐积累。

流程：对话中选择当天任务 → 完成代码和说明 → 验证运行 → 提交到 GitHub。

| 2 | 2026-10-13 | [Python 石头剪刀布](days/2026-10-13-rock-paper-scissors/) | 随机对战、胜负判断、输入校验、战绩统计 |

## 第 1 天：猜数字

需要 Python 3，无第三方依赖。从仓库根目录运行：

```bash
python3 days/2026-10-12-guess-number/main.py
```

Windows 也可以使用：

```powershell
py days/2026-10-12-guess-number/main.py
```

游戏会随机选择 1～100 的整数，每次猜测后提示大小。猜中后显示有效猜测次数，并可以开始新的一轮。输入 `q`、按 Ctrl+C 或结束输入都可以退出。

非整数和超出范围的输入不会计入猜测次数。

## 第 2 天：石头剪刀布

需要 Python 3，无第三方依赖。从仓库根目录运行：

```bash
python3 days/2026-10-13-rock-paper-scissors/main.py
```

输入 `1`（石头）、`2`（剪刀）、`3`（布），或直接输入中文，与随机出拳的电脑对战。每轮显示胜负和累计战绩。输入 `q`、按 Ctrl+C 或结束输入可退出，并查看最终统计。无效输入不计入轮数。
