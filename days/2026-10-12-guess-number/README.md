# 第 1 天 · Python 猜数字

- 日期：2026-10-12（北京时间）
- 目标：完成一个可以在终端运行的小游戏。
- 依赖：Python 3 标准库。

## 已实现

- 随机生成 1～100 的整数，包含两个边界。
- 提示猜大或猜小，猜中后显示有效猜测次数。
- 拒绝空输入、非整数和超出范围的数字。
- 支持重复游玩，输入 `q` 随时退出。
- Ctrl+C 和输入结束时正常退出。

## 运行

在仓库根目录执行：

```bash
python3 days/2026-10-12-guess-number/main.py
```

## 涉及的基础知识

- `random.randint()`：生成随机整数。
- `input()` 和 `int()`：读取并转换输入。
- `while`、`if` 和 `elif`：循环与条件判断。
- `try` 和 `except`：处理无效输入与退出。
- 函数：分别组织单轮游戏和主流程。

小技巧：每次猜剩余范围的中间值，可以快速缩小范围。

## 验证

已通过：猜大、猜小、猜中、无效输入不计次、1 和 100 的边界、主动退出、重复游玩、EOF 和 Ctrl+C 退出；另已实际启动命令行程序并完成退出。
