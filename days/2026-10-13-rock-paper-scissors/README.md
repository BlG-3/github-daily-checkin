# 第 2 天 · Python 石头剪刀布

- 日期：2026-10-13（北京时间）
- 目标：与电脑连续对战，并统计本次游戏的胜负。
- 依赖：Python 3 标准库，无需安装第三方库。

## 运行

在仓库根目录执行：

```bash
python3 days/2026-10-13-rock-paper-scissors/main.py
```

Windows 也可以使用 `py` 代替 `python3`。

输入 `1`（石头）、`2`（剪刀）、`3`（布），或直接输入对应中文。电脑每轮随机出拳，石头胜剪刀、剪刀胜布、布胜石头，相同出拳为平局。

输入 `q` 或 `Q`、按 Ctrl+C、结束输入均可退出，程序会显示最终战绩。战绩仅保存在本次运行中，重新启动后清零。

## 已实现

- 支持数字与中文出拳，自动忽略输入前后的空白。
- 每轮显示双方出拳、胜负结果和累计战绩。
- 无效输入不计入轮数，也不会触发电脑出拳。
- 退出时显示总轮数、胜场、负场和平局数。
- 支持从未出拳就退出，以及中途结束输入。

## 涉及的基础知识

- `random.choice()`：从三种出拳中随机选一种。
- 字典：映射输入、保存战绩。
- 集合与元组：表达三种获胜组合。
- 循环、条件判断和异常处理：组织对战和退出流程。
- `unittest` 与 `unittest.mock`：固定输入和电脑出拳，验证交互流程。

## 验证

从仓库根目录运行自动化验证：

```bash
python3 -m unittest discover -s days/2026-10-13-rock-paper-scissors -v
```

已通过 6 项测试，覆盖全部 9 种对战组合、数字与中文输入、空白处理、多轮战绩、无效输入不计次、大小写退出、EOF 和 Ctrl+C 退出时保留战绩。另已实际启动命令行程序，验证对战后退出、立即退出和 EOF 退出。
